# DIMP AI Opportunity Matching Game

A single-page web application to help employees identify the correct AI problem type based on business questions.

## Features

### Two Game Modes

**Exercise 1: AI Opportunity Match** (Blue Theme)
- 5 business questions covering key AI techniques:
  - **Prioritize**: Ranking work items by importance
  - **Anomalies**: Detecting unusual patterns
  - **Cluster**: Discovering unknown groups
  - **Classify**: Assigning categories
  - **Predict**: Estimating future outcomes

**Exercise 2: AI Capability Match** (Green Theme)
- 4 business questions covering AI capabilities:
  - **Read Text**: Understanding written content
  - **Recommend**: Suggesting best options
  - **Estimate**: Predicting numerical values
  - **Optimize**: Finding best settings

### Game Mechanics

- Interactive multiple-choice format with randomized options
- Immediate feedback with detailed explanations
- Score tracking for each exercise
- Combined score display
- Progress indicator (Question X of Y)
- Professional corporate presentation style
- Fully responsive and mobile-friendly

## Files

- `index.html` - Main HTML file with menu and game screens
- `style.css` - Styles with theme variables for blue/green modes
- `script.js` - Game logic with both exercises
- `README.md` - This file

## Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings → Pages
4. Under Source, select "main" branch and click Save
5. Your site will be live at `https://<username>.github.io/<repository>/`

## Usage

1. Open `index.html` in a web browser
2. Select an exercise from the main menu
3. Answer questions by clicking the matching option card
4. View immediate feedback with explanations
5. Check your score at the end
6. Return to menu to switch exercises or play again

## Tech Stack

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript (ES6+)

No frameworks or build tools required!
